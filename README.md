# AI Daily News 🤖📰

每日定时任务自动扫描并整理的最新 AI 行业资讯，按日期归档。

## 栏目结构

每期报告按以下五大主题分组：

1. **大模型与 AI 产品发布/更新** — OpenAI、Anthropic、Google、Meta、DeepSeek、阿里通义、字节豆包、月之暗面等
2. **行业融资、并购与重大商业动作**
3. **AI 芯片、算力与基础设施进展**
4. **重要开源项目与论文**
5. **AI 监管与政策动向**

每条资讯均注明来源与时间，每期末尾附关键要点摘要。
