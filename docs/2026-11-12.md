## 关键要点摘要

1. **"决策模型"成为新范式**：谷歌发布 Gemini Decision 1（单次前向评分、输出零成本、延迟 150–250ms），跳过逐 Token 生成，为分类/评分/选择类任务大幅降本，可能重塑轻量推理 API 市场。
2. **Anthropic IPO 进入冲刺期**：获数倍超额认购、估值约 1.4 万亿美元，预计 11月19日挂牌纳斯达克；IPO 前密集发布 Fable/Mythos 5.2 与办公三件套，直指微软生产力生态（微软股价当日跌 2.2%）。
3. **中国大模型开源密集冲顶**：Kimi K3（2.8 万亿参数）、美团 LongCat-2.5（纯国产算力训练）、百度文心 5.5、小米 MiMo-V2.6 集中发布，开源规模与国产算力自主性同步抬升；阿里平头哥分拆赴港上市再添资本化信号。
4. **AI 算力竞赛演变为"科技+能源+金融"综合战**：英伟达联合六大华尔街机构动员超 5000 亿美元资本、博通传出最高 1000 亿美元融资计划，CoreWeave 转向芯片抵押贷款——GPU 融资资产化成为行业新逻辑。
5. **监管从自查转向强制审计**：纽约州 RAISE 法案落地（强制注册、72 小时上报、最高 300 万美元罚款）并组建 80 人州立团队独立测试模型；同时头部厂商罕见联合呼吁放慢训练以换安全窗口。
