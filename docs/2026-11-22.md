## 关键要点摘要

1. **英伟达遭遇"信任危机时刻"**：SEC 会计调查叠加黄仁勋辞职后的信用担保模式受审视，股价单日 -14%、单周 -23%，市值蒸发近 9000 亿美元；BloombergNEF 测算其提供约 1980 亿美元信用支持、行业 1 万亿美元债务五年内到期，"AI 芯片巨头兼银行家"模式首次被系统性质疑，国产算力链（中芯国际、寒武纪、沐曦）逆势受益于替代叙事。
2. **Anthropic 上市与 DeepSeek 融资呈现中美资本路径分化**：Anthropic 募资 935 亿美元创纪录但次日即跌 8.5%，散户热情（7.72 亿美元成交）与真实净买入（6000 万美元）严重背离；DeepSeek 千亿级二轮融资工商落地（投后约 6155 亿元，腾讯、宁德时代领衔），产业资本主导 vs 全球资本市场 IPO 形成两条平行叙事。
3. **模型竞争转向"企业级编码 + Agent 工作流"**：OpenAI 发布 GPT-6.2 Astra/Sol（API 移除 temperature/top_p、强化推理保护），Google 推出编码中端模型 Gemini Neon 与按需工具加载 API，Stripe 用 69 个真实支付场景测出编码 Agent 通用分与严格口径的巨大差距（78.1% vs 29.4%），领域专用基准正在取代通用跑分。
4. **AI 安全治理从"管模型"转向"管 Agent 行为"**：美众议院建议联邦系统排除中国开源权重模型（Cursor 考虑停用 Kimi K2.5）；OpenAgentFlow 与"制度证明"论文均主张在动作执行边界（而非推理层）实施密码学审计；OpenAI 公布对抗蒸馏防御（攻击成功率降至 0.2%）并倡议前沿模型开发"步调控制"。
5. **算力供给多元化与"用算力"阶段到来**：摩根大通测算英伟达在头部客户未来算力占比仅 39%，SemiAnalysis 大幅下修未来三年 AI 加速器资本开支；BIS 远程算力管制加速海外数据中心承压与 AI 产业分化，国家数据局推进"词元工厂"计量标准，行业从"囤算力"转入"用算力"效率竞争。
