## 关键要点摘要

1. **国产旗舰开源模型密集突破"多模态+操作"组合**：腾讯混元 Hy4 正式版首次引入视觉理解与 Computer Use、参数达 770B，DeepSeek V4 将百万上下文下放为标配——开源模型正从"能对标"走向"可托付"，Agent 落地能力成为新一代竞争焦点。
2. **AI 编程赛道并购加速**：OpenAI 收购 Pierre Computer、Meta 收购 Conductor，巨头围绕"AI 原生代码工具链"补齐能力，并与 GitHub 形成正面竞争。
3. **算力自主紧迫性上升**：英伟达对华算力服务管制传闻叠加 RTX Pro 5500 交付仅约订单 1%，高端算力国内外价差近 5 倍；同时后摩智能、凌川科技等国产芯片公司获大额融资，国产替代路径获得资本加持。
4. **智能体治理进入标准化阶段**：中国 20 家单位联合发布《智能体发展自律公约》，覆盖信任体系、互联标准与用户控制权；蓝皮书数据显示我国日均词元调用量两年增长超千倍，智能体产业规模快速扩张。
5. **模型可验证性成为新议题**：Anthropic 开源 FlashProve 用零知识证明验证"回答出自指定模型"，17 秒识破套壳，为开源模型生态建立信任基础设施提供了新范式。
