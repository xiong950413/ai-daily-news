## 关键要点摘要

1. **OpenAI 处境艰难：产品整合引发用户反弹、人才持续流失**：12 月起 ChatGPT 的推理对话、Work Agent 与 Codex 任务将共享 Token 额度，付费用户不满；Business Insider 统计年内已有 12 位高管离开或退居二线，Anthropic 以超常规薪酬抢人，GPT-6.2 表现不及预期被指放大内伤。
2. **国内 AI 监管聚焦"数据要素 × 人工智能"**：国家数据局发布征求意见稿，明确数据产权制度进入 AI 训练/推理场景并要求企业建立输出风险防控机制；我国已牵头制定 78 项 AI 国际标准，其中数据质量标准被欧盟采纳。
3. **英伟达财报与监管压力并存**：数据中心单季收入 1076 亿美元（同比 +110%）、Vera 平台密集上新，但据报暂停向四个东南亚国家出货服务器，TrendForce 预估 2027 年 HBM/DRAM 供应持续吃紧——AI 基建"产业扩张"与"资本拷问"结构性分化。
4. **国产开源密集释放、AI for Science 成新战场**：百度开源 Apache 2.0 的 ERNIE 5.5 Flash Preview（280B/1M 上下文）、蚂蚁 Robbyant 开源具身建图导航双模型、微软开源端侧 Aion 1.0；腾讯、上海 AI 实验室、月之暗面、MiniMax 集体切入 AI4S，该赛道年内融资已超 200 亿元。
5. **Agent 生态标准之争升温**：谷歌宣布 2027 年 2 月起强制 Agent 经 MCP 访问 Workspace，Anthropic 让 Claude Artifacts 变成可安装桌面应用，Cloudflare 推出面向 Agent 的站点搜索端点——平台入口与访问协议成为新的竞争焦点。
