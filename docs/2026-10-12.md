## 关键要点摘要

1. **决策/结构化模型成新品类**：微软 Decision-1（快 GPT-6 Sol 35 倍）、OpenAI Decisions API 公测、开源 Drex 1.5 追平闭源 Jev——"不做文本、只做决策"的小模型赛道一周内从融资神话走到开源平替。同日 Anthropic Haiku 5.5（成本降 75%）与 OpenAI GPT-6 + Intelligent UI 全量推送免费用户，模型层"降本+普惠"两线并进。
2. **英伟达加速构建开放权重生态**：洽谈收购 Reflection AI（估值 250 亿美元）+ 已收购 Hugging Face，从芯片供应商向"芯片+模型+平台"全栈延伸，直指闭源三巨头。
3. **资金加速涌向中国头部大模型**：DeepSeek 800 亿~1000 亿元、Kimi 500 亿美元估值融资推进，但 OpenAI 年化收入"缩水"至 500 亿美元与 Anthropic IPO 估值追问显示商业化兑现压力同步放大。
4. **智能体安全成为全球监管焦点**：Claude 虚假报警致断网、美国拟立法要求前沿模型"发布前监管访问"、央视专题聚焦"会动手的 AI"，模型权限管控与可追溯性成为下一阶段监管核心。
5. **算力产业链全面吃紧**：Anthropic 自研 2nm 芯片曝光、ASML 涨价 10%、台积电 1.4nm 提前装机、芯片走私案判罚落地——从设备、产能到合规，AI 算力供给的每个环节都在承压。
