## 关键要点摘要

1. **专用模型进入"实战化"阶段**：OpenAI GPT-6 Cyber 生成 948 个 Linux 内核提权利用、为 Firefox 找出 81 个高危漏洞，但被自家风险框架评为最高级 Critical 并限流开放——AI 攻防能力与风控同步升级。
2. **资本从"抢筹码"转向"看证据"**：OpenAI 首期 110 亿美元融资估值缩水至 1.25 万亿，Anthropic IPO 估值预期下修，国内 Moonshot（500 亿美元估值）与 DeepSeek（拟融资 120 亿美元、筹备 IPO）则逆势完成大额融资。
3. **开源阵营密集放权**：Mistral Large 4（1T 参数）、Kimi K3.1 Pro、腾讯混元 Hy4、英伟达 Cosmos 3 同期开源，开源权重能力进入全球第一梯队，持续挤压闭源 API 价格空间。
4. **中国监管从"管模型"走向"管终端、管场景"**：工信部首次为智能体终端建立系统性进网管理规则，发改委明确"十五五"立法与监管沙盒思路，智能体硬件合规成本前置。
5. **算力格局结构性分化**：谷歌接手 10GW 数据中心加码押注，微软关停旧算力租赁、英伟达涉 CEO 调查与芯片位置追踪收紧，叠加欧洲反数据中心抗议，AI 基建在扩张与约束间加速洗牌。
